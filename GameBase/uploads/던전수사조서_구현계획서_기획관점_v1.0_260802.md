## 1. 목적과 완성 정의

### 1.1 완성 정의 (DoD)

| 등급 | 정의 |
|---|---|
| **최소 완성선** (제출 가능) | 튜토리얼→EP001→EP004 **15노드를 폴백 대사만으로 완주 가능**. 9개 전투가 완전 진술·강제 자백·부분 실패 3분기로 작동. 엔딩 1종(트루). 사건 등급 S~F 산출 |
| **목표 완성선** | 최소선 + P1 덱빌딩 가시화(도장·포스트잇·클립·3택1) + P2 AI 변주(검증·폴백 전환 포함) |
| **초과 달성** | + 엔딩 3종, 이벤트 전용 컷신, QTE 옵션 등 P3 |

"AI가 꺼져도 완주 가능"을 최소선에 두는 이유: AI 변주는 P2이며(기준 2 §10), AI는 표현만 바꾸고 정답을 바꾸지 않는다(기준 2 §9.3). 폴백으로 완주되는 게임이 먼저 있어야 그 위에 AI를 얹을 수 있고, 시연 중 AI 장애가 나도 데모가 끊기지 않는다.

### 1.2 이 문서가 다루지 않는 것

개발 스택·엔진 선정과 코드 구조(후속 개발 관점 문서), 사건 3개의 대사 전문(M2~M3 산출물), 애셋 개별 파일의 발주 상세(§8은 총량과 원칙까지만).

## 2. 제품 요약 (기준 문서 재확인)

### 2.1 정체성 한 줄 (기준 2 §11)

> 플레이어는 방어막을 보고 거짓말을 맞히는 것이 아니라, **진술을 육하원칙 주장으로 분해하고, 증거가 실제로 어디까지 입증하는지 판단한 뒤, 질문·확인·모순·압박의 순서를 덱으로 설계해 신뢰 가능한 자백을 확보한다.**

### 2.2 코어 루프 — 한 턴 (기준 2 §2.1)

진술 → 육하원칙 6태그 갱신 → 동일 외형 방어막 2~3개 → 사건 조서에서 증거·입증 범위 확인 → 카드 선택+태그 선택+증거 첨부 → 판정(직접 모순/간접 의심/불충분/진실 공격) → 적 대응(반사·셔플·파쇄·봉인 등) → 종료 체크(필수 주장·평정심·강압 수사·실패 조건)

### 2.3 수직 슬라이스 구성 — 15노드 (순서 고정)

| 에피소드 | 노드 진행 | 플레이어가 배우는 것 |
|---|---|---|
| 튜토리얼 「믹스커피 절도」 | 물컹이 → 쓰레기통 감식 → 하피 → CCTV·기록 복구 → **미노타우로스** | 진술 읽기, 증거 입증 범위, 다중 방어막, 스위트 스팟, CP 보존 |
| EP001 「빨간물 횡령」 | 고블린 → 창고 제한 조사 → 오크 → 장부 복원 → **서큐버스** | 강압 반사, 3턴 타임어택, 증거 원본/사본 품질, 도장·포스트잇·클립 |
| EP004 「GATE-04 부실 공사」 | 드워프 → 기계실 제한 감식 → 사이클롭스 → 티켓 거래 선택 → **타락한 용사** | 블라인드 셔플, 자원 압박, 증인 보호, 물증·디지털·증언·금융 교차 검증, 강압 한계 40% |

전투 9(일반 6 + 보스 3), 비전투 이벤트 6. 일반 용의자 6명에게 육하원칙 6대 기믹을 일대일 배정(기준 2 §3): 물컹이[누가 잠금] / 하피[무엇을 QTE] / 고블린[어떻게 강압 반사] / 오크[언제 파쇄 타이머] / 드워프[어디서 블라인드 셔플] / 사이클롭스[왜 CP 봉인].

### 2.4 로그라이크성 (해커톤 범위)

사건 순서와 진범·증거 규칙은 고정. 변주는 4요소로만 확보한다(기준 2 §4): ① 전투 후 3장 중 1장 카드 보상 ② 비전투 이벤트의 자원·증거 선택 ③ AI가 같은 Truth Seed를 다른 말투·문장 순서로 표현 ④ 미끼·사생활 방어막 위치 변주.

## 3. M0 게이트 — 콘텐츠 제작 전 확정할 규칙

M0의 목적은 하나다. **시트를 쓰기 시작한 뒤 규칙이 바뀌어 9개 전투를 다시 고치는 사태를 막는다.** 아래 전 항목이 '확정'되기 전에는 전투 시트(부록 A) 작성을 시작하지 않는다.

### 3.1 기준 2 §1이 이미 지시한 5대 정리 — 기획 작업으로 전환

| # | 규칙 | 기획 작업 | 산출물 |
|---|---|---|---|
| R-1 | 육하원칙 밖 태그 금지 | 시나리오 v1.0의 토큰(이후 행동, 목격 여부, 판매/환불, 검사 결과 등)을 6태그로 전수 재매핑. 물컹이·드워프는 기준 2에 완성본이 있으므로 **나머지 7개 전투를 신규 작성** (예: 물컹이 '목격 여부'→[누가], 드워프 '이후 행동'→[어떻게], 오크 '판매/환불'→[무엇을]/[어떻게]) | 재매핑표 9종 (전투 시트에 통합) |
| R-2 | 보스 거짓말을 정답표처럼 동시 나열 금지 | 보스 3종을 주장 라운드제(라운드당 동일 외형 방어막 2~3개)로 분해 — 기준 2 §5~7의 라운드표를 시트 정본으로 이관 | 보스 시트 3종 |
| R-3 | 스위트 스팟 통일 | **1~30% 진술 확보 / 0% 심리 붕괴**로 전 캐릭터 통일. v1.0의 개별 수치(하피 30, 서큐버스 25, 사이클롭스 35)는 폐기하고 개성은 피해 증폭·회복·봉인으로 표현. **[진술 확보]는 버튼**(v1.0의 '확인 카드/증언 확보 카드' 표기 폐기) | 규칙 정본 1부 |

| R-5 | 이벤트에 실패와 비용 필수 | 이벤트 6종 각각에 교환 자원 2종 이상(스트레스·DP·파트너 신뢰도/쿨타임·증거 등급·다음 방어막 수·강화 기회·사건 등급) 명시 | 이벤트 시트 6종 |

## 4. 구현 범위와 컷라인 (1인 개발 보정)

### 4.1 P0 — 세 에피소드가 처음부터 끝까지 작동 (기준 2 §10 유지)

① 고정 Truth Seed 9개 전투 ② 육하원칙 6태그 공통 UI ③ 동일 외형 방어막 2~3개 ④ 카드군 최소 4종(질문·사실 확인·모순 지적·완급 조절) ⑤ 증거 메타데이터와 판정 ⑥ 스위트 스팟과 [진술 확보] ⑦ 스트레스·강압 수사·평정심·CP ⑧ 일반 용의자 6대 기믹 ⑨ 보스 3종 페이즈 ⑩ 완전·부분·강제 자백 분기.
여기에 1인 보정으로 **폴백 대사 전량을 P0에 포함**한다 — "AI 없이 완주"가 P0의 정의이기 때문이다.

### 4.2 P1 — 덱빌딩이 보임 (1인 최소선)

도장 2종(파랑·빨강) / 포스트잇 6종 중 **3종 우선**([언제]·[어떻게]·[왜] — 오크 타이머·서큐버스·사이클롭스 대응이 체감 큼) / 클립 2레시피(진술 고정·연속 추궁) / 전투 후 3택1·보스 후 2택 보상 / 사건 등급 S~F.

### 4.3 P2 — AI 게임으로 보임 (go/no-go 게이트)

Truth Seed 기반 진술 표현 변주 / 태그 span과 JSON 검증 / 같은 진실의 재질문 변주 / 실패 시 폴백 문장 전환 / 개발자용 판정 로그.
**게이트: M4 진입 시점에 P0 완주 빌드 + 출력 검증기 + 폴백 전환이 갖춰져 있지 않으면 P2를 켜지 않는다.** 시연용 핵심 진술은 사전 생성·검증 캐시를 우선 사용한다(§7.4).

### 4.4 P3 — 여유가 있을 때

엔딩 3종(기본은 트루 1종) / 이벤트 선택별 전용 컷신 / QTE 난이도 옵션 / 추가 카드·유물 / 사건별 대체 미끼 진술 세트.

### 4.5 컷 순서 (스코프 초과 시 이 순서대로 버린다)

1. P3 전량 → 2. 포스트잇 3종→2종, 클립 2→1 → 3. P2 변주 범위 축소(보스전 폴백 고정, 일반전만 라이브 변주) → 4. QTE 2종을 연출만 남기고 자동 성공 처리 → 5. 이벤트 퍼즐 단순화(연결·배치형 B, 제한 조사형 C → 선택지형 A로 강등) → 6. 엔딩 분기 축소(트루만, 조건 미달 시 노멀 텍스트 1장) → 7. 애셋 컷(§8.7).

**어떤 경우에도 지키는 것: 15노드 완주 / 3분기 / 동일 외형 방어막 / 증거 입증 범위 판정.** 이 넷이 무너지면 이 게임이 아니다.

## 5. 기획 산출물 목록 — 무엇을 만들어 넘기는가

1인 개발이라도 "기획 모자를 쓴 나"가 "개발 모자를 쓴 나"에게 넘기는 산출물의 경계를 지킨다. 경계가 무너지면 구현하면서 규칙을 즉흥 수정하게 되고, 그 비용은 9개 전투 전체의 재검수로 돌아온다.

### 5.1 데이터 패키지 구조 (참고 1 방법론 채택)

### 5.3 콘텐츠 제작 절차 — 전투 1개 기준 (참고 1 §23 채택)

순서 고정. **대사는 마지막에 쓴다.** 대사부터 쓰고 태그를 역산하면 원자성이 무너지고 논리적으로 풀 수 없는 사건이 나온다.

① Truth Seed 발췌(이 전투에 걸리는 진실만) → ② 6태그 주장 분해(내부 판정: 모순/진실/사생활/잠금) → ③ 초기 공개 vs 질문으로 열리는 것 구분 → ④ 증거의 입증 범위·"입증하지 못하는 것" → ⑤ 라운드·필수 주장 → ⑥ 기믹(트리거·효과·카운터플레이) → ⑦ 결과 분기·보상·플래그 → ⑧ 폴백 대사 → ⑨ AI 변주 지시.

전투 시트 제출 전 셀프 검수(참고 1 §23.3 발췌·수정):

- 거짓 주장의 입증 방법을 **2가지 이상** 적을 수 있다 (증거 소실·파쇄 대비)
- 각 증거의 "입증하지 못하는 것"이 1문장으로 적혀 있다
- 저항이 강한 **진실** 주장이 1개 이상, 사건과 무관한데 숨기려는 주장(사생활)이 1개 이상 있다
- 그럴듯하지만 불충분한 조합(국밥집 영수증형 함정)을 최소 1개 심었다
- 필수 주장은 2~3개다 (최종 보스만 4개 예외)
- 기믹이 이미 성립한 추리를 되돌리지 않는다

## 7. AI 변주 스펙 (P2)

### 7.1 역할 원칙

**엔진이 심판, AI는 배우.** 사건 진실·판정·보상은 데이터가 소유하고, AI는 엔진이 확정한 주장을 캐릭터의 말투로 연기한다. AI를 꺼도 폴백 문장으로 완주 가능해야 하며(§1.1), 이것이 P0와 P2의 경계다.

### 7.2 변주 허용·금지 (기준 2 §9.3 정본)

| 바꿔도 되는 것 | 바꾸면 안 되는 것 |
|---|---|
| 말투와 어휘 / 문장 순서 / 사생활 방어막의 소재 / 진실 방어막의 위치 / 감정 반응·종족별 표현 | 실제 사건 진실 / 필수 주장 / 증거의 입증 범위 / 직접 모순 판정 규칙 / 보상과 실패 조건 |

### 7.3 입출력 계약 (기획이 정의하는 부분)

- **입력**: 캐릭터 프로필(종족·직업·성격·말투·금지 표현) + 이번 라운드에 말할 주장 ID 목록 + 판정 리액션 키
- **출력**: 문장 + 문장 내 태그 위치(span). span이 6태그와 1:1로 매핑되지 않으면 검증 실패 → **같은 주장 ID의 폴백 문장으로 즉시 교체** (게임 무정지)
- **금지 표현 목록**(기획 작성): 정답 암시 어휘("사실은…", "거짓말이지만"류), 사건에 없는 인물·시각·장소, 진실/거짓 문장의 문체 차등
- 검증 실패율이 10%를 넘으면 검증기를 늦추지 말고 프롬프트를 고친다 (참고 1 §26.3)

### 7.4 시연 안전장치

심사·시연의 핵심 구간(물컹이 완전 진술, 미노타우로스 자백, 최종 논고)은 **사전 생성 후 검증을 통과한 캐시 문장을 재생**한다. 라이브 생성은 일반 라운드에서만 보여준다. "AI 게임으로 보임"과 "시연이 절대 안 끊김"을 동시에 잡는 방법이다.

## 8. 애셋 계획 (참고 2 방법론 × 기준 캐스트 재산정)

### 8.1 채택하는 방법론 (참고 2 그대로)

- **표기 범례**: 🎨 이미지 / 🎬 애니메이션 / ✨ 이펙트 / 🔊 SFX / 🎵 BGM / 📄 데이터 — 본 계획서와 후속 발주서에서 동일하게 사용
- **공통 제약**: 내부 해상도 640×400 정수배 업스케일, 씬당 16색 팔레트, 안티앨리어싱 금지(도트 계단 유지), 애니메이션 3~4프레임, 상태 변형은 스프라이트시트 1장 통합, 명명 규칙 `카테고리_이름_상태.png`
- **포트레이트 파츠 방식**: 베이스 1장 + 표정 파츠(눈썹·땀·입) 오버레이
- **AI 아트 파이프라인 4단계**: 생성 모델 초안 → 640×400 도트화 → 16색 팔레트 리매핑 → 수기 리터치·파츠 분리. 16색 강제 리매핑이 곧 스타일 통일 장치라는 논리를 그대로 채택

참고 2의 캐릭터(코볼트·미믹·픽시)와 화면(크레이지 보드·휴게실·자판기·암시장·브리핑 룸)은 본 빌드 범위가 아니다. **기준 문서의 15노드·12캐릭터로 목록을 다시 만든다.** 단 물량 통제 장치 — 공용 배경, 파츠 재사용, 카드 일러스트 생략(텍스트+분류 아이콘), 이벤트 컷 카테고리 공용화 — 는 그대로 가져온다.

### 10.2 루트 QA (M2~M3)

9개 전투 × 3결과(완전·강제·부분) = **27셀 도달 매트릭스**를 실플레이로 채운다. 특히 하피·사이클롭스 강제 자백 시 보스 방어막 +1과 증거 등급 하락이 실제 다음 전투에 반영되는지 확인.

### 10.3 연계 QA

부록 D 13플래그 각각 on/off 두 갈래 실플레이. 우선 3종: **빨간 장부 원본/사본/소각** · **오크 원본 로그 보존 여부** · **E4-04 3선택**(거절/녹음/수락→배드 엔딩).

### 10.4 공정성 QA — 정답 비노출 (참고 1 검증 규칙 차용)

방어막 3유형(모순·자신감·사생활)의 외형이 완전히 동일한가 / 저항·내구 수치가 진실 여부와 상관을 갖지 않게 배치했는가 / 화면·전달 데이터 어디에도 정답 표시 필드가 없는가 / 실패 피드백이 "부족한 범위"만 알려주고 정답 증거명을 노출하지 않는가.

### 10.5 AI QA (M4)

동일 장면 변주 3회 생성 → 판정 결과 동일 / 강제 실패 주입 → 폴백 전환이 자연스러운가 / 금지 표현 스캔 / 사건에 없는 인물·시각·장소 언급 탐지.

### 10.6 밸런스 관측 지표 (M5 목표)

일반 전투 6~10턴, 보스 10~16턴 / 첫 플레이 강압 패배율 20% 미만(단, 최종 변호인 구간은 의도된 긴장 구간) / 스위트 스팟을 지나쳐 0%로 추락하는 비율 30% 미만 / 시연 컷 기준 튜토리얼 15~20분.
