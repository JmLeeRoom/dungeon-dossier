# 📁 [게임 기획서] 던전 수사 조서 - 핵심 플레이 시스템 정의서

## 1. 코어 스테이터스 (Core Status)

게임의 긴장감을 유지하는 4가지 핵심 자원입니다.

- **[스트레스 (HP)]:** 형사의 글로벌 체력. 0이 되면 과로사로 런(Run) 실패. 적의 '왜(동기)' 기믹이나 비전투 이벤트 등에서 깎임.
- **[강압 수사 (Penalty)]:** 전투 내 게임오버 수치. 100% 도달 시 엘프 노조 변호사가 난입해 런 실패. (특정 보스는 한계치가 더 낮음)
- **[평정심 (Enemy HP)]:** 용의자의 멘탈 게이지 (기본 100%). 이를 깎아 진실을 유도하는 것이 목표.
- **[CP (Cost)]:** 턴마다 회복되는 형사의 행동력. 카드 사용 시 소모.

## 2. 대질 심문 메커니즘 (전투 시스템)

텍스트 어드벤처의 '모순 지적'과 카드 배틀을 결합한 핵심 시스템입니다.

- **진술 생성 및 태그화:** 턴 시작 시 용의자의 변명이 진술 보드 위에 6개의 '육하원칙 태그(누가/언제/어디서/무엇을/어떻게/왜)'로 배치됨.
- **다중 방어막 (함정 시스템):**
    - 용의자는 진술 중 2~3곳에 동시에 방어막을 전개함. 이 중 오직 하나만이 증거와 모순되는 '진짜 거짓말(약점)'임.
    - **정답 타격:** 단서와 모순되는 진짜 거짓말 태그를 공격하면 방어막이 파괴되며 평정심에 큰 데미지를 줌.
    - **오답 타격 (함정):** 진실에 씌워진 방어막을 공격할 경우 데미지는 들어가지 않고, **[강압 수사] 게이지가 크게 상승**하는 페널티 부여.
- **스위트 스팟 (진엔딩 분기):** 평정심을 0%로 만들면 '허위 자백'으로 처리됨. 평정심을 **30% 이하**로 아슬아슬하게 맞추면 숨겨진 진실을 털어놓으며 '결정적 증거(연계 사건 트리거)' 획득.
## 3. 3단계 카드 강화 시스템 (충돌 방지 설계)

90년대 서류 결재 시스템을 모티브로 한 위계가 분리된 덱빌딩 시스템입니다.

- **1단계 [결재 도장 - 스탠스 변경]:** 노드에서 카드의 영구 스탯 변경. (파란 도장 = 논리/안정형, 빨간 도장 = 강압/폭딜형)
- **2단계 [형광 포스트잇 - 모듈 장착]:** 특정 육하원칙 태그 타격 시 보너스를 주는 모듈. 카드 원본 훼손 없이 언제든 탈착 가능. (1회차 클리어 후 해금)
- **3단계 [서류 클립 - 카드 병합]:** 정해진 레시피로 두 장의 카드를 융합해 상위 카드 생성. 재료 카드의 도장과 포스트잇 효과를 그대로 상속받음.
## 4. 로그라이크 진행 구조 (런 구성)

리플레이성과 서사적 몰입감을 동시에 잡는 에피소드 배정 시스템입니다.

- **기본 진행 (랜덤 테마):** 챕터(Act) 시작 시 3개의 미제 사건 중 하나를 무작위로 배정받아 수사 진행.
- **인과율 시스템 (진엔딩 루트):**
    - 보스전에서 '스위트 스팟(평정심 30%)'을 달성하여 **[결정적 증거]** 유물을 획득했을 경우 발동.
    - 해당 증거를 소지한 채 다음 챕터로 넘어가면 랜덤 배정이 무시되고 스토리가 직접 이어지는 확정 연계 사건(예: 횡령 ➔ 살인 ➔ 부실 공사)이 등장.
    - 이전 사건의 증거가 다음 보스의 절대 기믹을 파훼하는 키 카드로 사용됨.
